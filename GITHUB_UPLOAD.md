# Publish your project on GitHub

Suggested repository name: `Public-Health-Dietary-Analysis-Python`

Suggested description: `Python analysis of CDC NHANES and USDA dietary data: validated joins, dietary feature engineering, visualizations, and exploratory cardiovascular health models.`

1. Extract the downloaded ZIP on your computer.
2. Sign into GitHub and select **New repository**.
3. Enter the name and description above. Choose Public if you want employers to see it. Do not initialize it with a README, since this package includes one.
4. Create the repository, then choose **uploading an existing file** (or **Add file → Upload files**).
5. Open the extracted `public_health_python` folder. Upload its contents so README.md appears at the repository root. Include the `outputs` folder and its contents; do not upload the ZIP itself.
6. Enter a commit message such as `Add reproducible public health Python analysis` and commit.
7. Open the README and notebook to check that charts and results render. If GitHub cannot preview the notebook, download it or open it in Colab.
8. Pin the repository to your GitHub profile. Add its URL to your resume project entry.

No raw participant-level files are included in this package. Fresh data download automatically when the code runs. `data/` is excluded by .gitignore; do not upload locally downloaded source files manually.

Before interviews, run the notebook yourself and review PORTFOLIO_NOTES.md. Start by practicing the join, validation, and score sections.
